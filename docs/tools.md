Add 1-50 driving or reference sketch dimensions; each returns its expression. The sketch is solved to every value and read back; fixed geometry never moves. horizontal/vertical measure the x/y extent (they do not make a line level). Edit a value later with nx_set_expression.

**Project model geometry into sketch** · effect `model` · NX 2406: tested (all variants); 18 checks in `acceptance/sketch/sketch_projection_default.json`

Bring model geometry into a sketch as associative curves that follow model changes. project: edges or curves onto the sketch plane; intersect: faces with the sketch plane.

| Argument | Type | Default | Notes |
| --- | --- | --- | --- |

| `objects` | array[1-200] of Ref | required | project: edges or curves; intersect: faces |

### `nx_get_sketch`

Read a sketch: frame, curves, constraints with dimension expressions, solver status. Curves are in sketch-local and part coordinates with dof (remaining degrees of freedom, 0: fully constrained); constraints name the point of each curve they use.

| --- | --- | --- | --- |
